# 최소 버전 평가 기록

2026-10-03 로컬 검증. 실서비스 성과가 아닌 합성 데이터 실험입니다.

## 재현 조건

- macOS 26.5.2 arm64, Python 3.12
- numpy 2.5.3, pandas 3.0.6, scipy 1.18.1, implicit 0.7.3
- 생성 시드 42, 유저 100명, 14일, 카탈로그 25개
- 이벤트 47,547건 / 클릭 15,139건 / 상위 3개 클릭 점유율 39.5%
- ALS factors=16, regularization=0.05, iterations=20, random_state=42, CPU 단일 스레드
- confidence=1+40*log(1+click_count)
- 사용자별 마지막 클릭 1건 홀드아웃. 해당 사용자에 대해 홀드아웃 시각 이후/동시 이벤트도 학습에서 제외.
- 과거 클릭이 없는 유저는 평가 제외. 재방문 가능한 금융 위젯이므로 이미 클릭한 항목도 추천 대상.
- 사용자 간 전역 시간 분할은 적용하지 않음. 실제 온라인 실험을 대체하지 않음.

## 결과

| 모델 | Recall@10 | NDCG@10 | Coverage@10 | 평가 유저 |
| --- | --- | --- | --- | --- |
| 인기순 | 0.6500 | 0.3677 | 0.4000 | 100 |
| ALS | 0.8200 | 0.3960 | 1.0000 | 100 |

이는 생성기와 동일한 구조의 합성 데이터를 학습한 작은 실험입니다.
하이브리드 모델의 정확도·운영 응답 시간·CTR은 측정하지 않았습니다.

## 실행

```bash
python -m src.datagen.log_generator --n-users 100 --days 14 --seed 42
python -m src.batch.precompute --backend file --factors 16
python -m src.model.evaluator --factors 16 --k 10
pytest -m "not redis"
```

실행 중 기본 data/ 산출물을 생성하거나 교체하므로 보관할 실험 데이터가 있으면 별도 경로를 사용합니다.

## 기능 검증

파일 저장소를 다시 읽는 API 통합 테스트에서 기존 사용자와 신규 사용자 모두 추천 6개와 점수 기여도를 반환합니다.
장중·급여일 규칙, 카테고리 상한, 빈 학습 데이터 거부, 잘못된 요청 수량, 날짜의 시간대 변환도 테스트합니다.
Redis·Streamlit 데모는 이번 최소 버전 범위에 포함하지 않습니다.
